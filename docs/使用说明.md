# Flashduck 使用说明

> 面向已经组装完成的用户。第一次使用请按「联网 → 激活 → 唤醒」的顺序走一遍，大约 5 分钟。

---

## 一、它是什么

Flashduck 是一只**听得懂人话、但只会嘎嘎嘎**的机器鸭。

它有一双灵活的双腿、一个小脑袋瓜、一张小嘴巴。你跟它说话，它听得懂，也会照做；
但你等不到一句人话——回应你的永远是一声「嘎」，外加嘴巴张合、脑袋轻轻转。

它不怎么吵，也不刷存在感。你叫它，它应你一声；你让它做事，它就去做；
你不管它，它就眯着琥珀色的眼睛待在那儿，偶尔自己看两眼。

---

## 二、快速开始

| 步骤 | 做什么 | 看到什么 |
|---|---|---|
| 1 | 插上 USB 供电（或装好电池开机） | 屏幕亮起，眼睛出现，**琥珀色**、半眯着 |
| 2 | 联网 | 手机连它的热点，选家里的 Wi-Fi |
| 3 | 激活 | 屏幕显示 6 位数字，去 xiaozhi.me 输入 |
| 4 | 说「**小鸭小鸭**」 | 眼睛变**紫罗兰**、睁大，应你一声鸭叫 |
| 5 | 直接说你想让它干嘛 | 眼睛变**橙红**，嘎一声，然后动起来 |

---

## 三、第一次开机：联网

第一次开机（或没存过 Wi-Fi 时），它会自己进入配网模式。

**如果没自动进入：** 开机时点一下主板上的 **BOOT 键**（GPIO0）。

配网步骤：

1. 手机打开 Wi-Fi 列表，找到一个叫 **`Xiaozhi-XXXX`** 的热点（XXXX 是这台机器 MAC 的后四位），连上它，不需要密码；
2. 一般会自动弹出配置页；没弹的话，浏览器打开 **`http://192.168.4.1`**；
3. 在页面里选择你家的 Wi-Fi，输入密码，保存；
4. 设备会自动重启并连接。

> ⚠️ 只支持 **2.4GHz** Wi-Fi。5GHz 的 SSID 它扫不到。
> 连不上时，眼睛会一直是**青蓝色**、瞳孔缩小、来回扫视——这就是它在找网络。

联网成功后，眼睛会变成**绿色**、眯成月牙形，停留约 2 秒，然后回到琥珀色待机。

---

## 四、激活

联网后如果设备还没绑定过账号，会进入激活状态：

- 屏幕显示一串**数字激活码**（一般 6 位），同时它会逐个数字念出来（这是它唯一还会"说话"的场合，用的是预录的提示音）；
- 打开 **<https://xiaozhi.me>**，登录后进入控制台，添加设备，输入这 6 位码；
- 激活成功后，屏幕提示消失，进入待机。

激活只需要做一次。之后每次开机都会直接连上。

> 如果你用的是自建的 `xiaozhi-esp32-server`，激活方式以你的服务端为准。

---

## 五、唤醒与对话

### 唤醒词

**「小鸭小鸭」——要连说两遍。**

这是固定的唤醒模型，不是关键词匹配，说一声「小鸭」不会触发。安静环境下，正常音量、离它 1 米内最稳。

### 眼睛就是它的状态灯

| 状态 | 眼睛 | 颜色 |
|---|---|---|
| **待机** | 放松半眯，慢慢随机看，偶尔眨眼 | 🟡 暖琥珀 |
| **扫描 Wi-Fi / 连接中** | 睁大、瞳孔缩小、左右扫视 | 🔵 青蓝 |
| **刚连上网络** | 眯成月牙，约 2 秒后回待机 | 🟢 绿色 |
| **正在听你说** | 完全睁大、瞳孔放到最大、眼神定住 | 🟣 紫罗兰 |
| **正在回应你** | 眼睑放松、眼神活跃、眨眼变快 | 🟠 橙红 |

**怎么判断它被唤醒了：** 眼睛从琥珀色变成**紫罗兰色并且睁大**，同时应你一声短促的鸭叫。
如果眼睛纹丝不动、还是半眯的琥珀色，说明没听到，再说一次。

### 按键

- **单击 BOOT 键**：开始一轮对话（等于不用唤醒词直接说话）；它正在说/动的时候再按一下，是打断；
- **开机阶段单击 BOOT 键**：进入配网模式。

### 一轮对话长什么样

```
你说「小鸭小鸭」
  → 眼睛变紫，嘎一声（curious），嘴张两下
  → 进入聆听，你说「往前走两步」
  → 眼睛变橙，嘎一声（随机情绪音），嘴按某一种张法动
  → 它开始走
```

它听完会自动结束聆听，不用手动停。想打断就单击 BOOT 键。

### 动作优先

你在对话里真的让它做事时（"往前走两步"），**它先执行动作**，回话时的张嘴/转头动画会让位，
不会出现"先把嘴巴演完才肯走"的情况。

只是聊天、没有具体动作时，它才会安安静静地嘎两声、动动嘴和脖子。

## 六、它的声音

它的"嗓子"是 **13 段情绪鸭叫**：

> 生气、好奇、倔强、崩溃、兴奋、不耐烦、大笑、嗯、嘲弄、不、难过、是、是（快）

每叫一声，会从这 13 段里**随机**挑一段（不会连续重复同一段），再配一套**随机张嘴动作**。

张嘴动作一共 **18 种张法**：快两下、慢开慢合、先快后慢、先小后大、双峰、颤动、渐强渐弱、深呼吸……
所以同一个"嘎"，嘴型每次都不太一样。长叫声（比如 6.6 秒的"崩溃"）会切成几段，每段换一种张法。

**脖子也会跟着动。** 不是固定摆头，而是：

- 角度小（大多 8~30°，偶尔 35°），小店才显得活；
- 快慢混着来，同一段里可能先快后慢；
- 中间会停一下再转，转完回正；
- **和情绪挂钩**：开心时转得多转得快，难过时又慢又小，好奇时偏一边停住，生气时又快又冲。

所以你看它回话，是"嘴在动 + 头在轻轻转"，每一轮的节奏都不一样。

> 提示：`崩溃` 那段有 6.6 秒，偶尔会让它"哀嚎"很久。如果你不喜欢，可以在固件里去掉这一条。

## 七、你能让它做什么

用**自然语言**直接说就行，它自己会挑动作。说得越具体越容易触发。

### 走路

| 你说 | 它做 |
|---|---|
| "往前走两步" / "走一下" | 往前走 |
| "往后退" | 后退 |
| "转个身" / "往左转" | 原地转向 |
| "停下" / "别走了" | 立刻停住 |

### 身体

| 你说 | 它做 |
|---|---|
| "跳一下" | 原地跳 |
| "左右摇一摇" | 摇摆 |
| "蹲一下" | 上下蹲起 |
| "坐下" | 坐下（腿收起） |
| "站起来" / "回正" | 回到站姿 |

### 脖子和嘴

| 你说 | 它做 |
|---|---|
| "把头转向左边" / "看右边" | 转头 |
| "摇摇头" | 左右摇头（否定） |
| "看看四周" | 环顾一圈 |
| "叫一声" / "嘎一个" | 张嘴合嘴 1~3 次 |
| "咂咂嘴" | 快速小声咂嘴 |
| "打个哈欠" | 慢慢张嘴 + 歪头 |

### 鸭子专属小动作

| 你说 | 它做 |
|---|---|
| "好奇一下" / "歪歪头" | 侧头好奇 + 轻叫 |
| "理理羽毛" | 侧头理羽 + 咂嘴 |
| "开心地走两步" | 走两步 + 轻叫 |
| "伸个懒腰" | 伸懒腰（蹲起 + 张嘴） |
| "跳个舞" | 一小段鸭舞 |
| "啄一下" | 低头啄食 + 张嘴 |
| "困了" / "睡觉" | 困倦动作 |

### 关于"问它问题"

**它不会说话，所以别指望它"回答"你。** 电量、IP、状态这类问题，它答不出来，也不会念。

要看这些信息，走这两条：

- **串口日志**（最可靠）：USB 连电脑，115200 波特率，开机日志里就有 IP；
- **网页**：浏览器打开它的 IP，`/api/status` 能看到电量、充电状态、是否在动。

> 动作是由模型决定的，不是关键词表。它偶尔会挑一个相近的动作，或者先跟你聊两句再动——这是正常的。

## 八、网页调参

联网后，在浏览器打开 **设备的 IP**（日志里会打印，也可以问它"你的 IP 是多少"），端口 80。

页面是 **《Flashduck 步态调参》**，可以：

- 实时改髋部偏置、摆幅、脚踝幅度、相位、速度、摆头幅度；
- 点「走两步」看效果，「停止」立刻停；
- 调满意了点「保存」，参数写进 NVS，下次开机生效。

步态不对（走起来打滑、原地踏步、腿打架）先来这里调，不用改代码。

---

## 九、充电与电量

- 内置可充电锂电池，插 USB 充电；
- 充电时屏幕顶部电池图标会变化；
- 电量低时会有一段提示音，屏幕也会弹提示，及时充电。

## 十、常见问题

**叫不醒**
- 唤醒词要连说两遍「小鸭小鸭」；
- 环境太吵、离太远、语速太快都会影响，靠近一点、慢一点再说；
- 它正在回应你的时候说唤醒词，会打断当前回应、重新开始聆听。

**连不上 Wi-Fi**
- 只支持 2.4GHz；
- 密码里如果有特殊字符，先在手机热点上试一下；
- 眼睛一直青蓝色扫视 = 在找网络；重新进配网模式（开机时点 BOOT 键）。

**它不说话了**
- 这是设计：它只会嘎嘎叫，不会说人话。

**有声音但嘴巴不动**
- 你刚让它做动作时，说话动画会让位给动作（动作优先），所以可能"边走边嘎"而嘴没动；
- 如果它正在走路/做动作，这一声也会主动跳过——宁可不出声，也不做"只出声不动嘴"的穿帮；
- 等它停下来再叫它。

**舵机一直抖 / 发热**
- 轻微抖动正常（离合舵机 + 重力的静差）；
- 持续大力抖动或发烫，通常是堵转或供电不足，立刻断电检查结构有没有卡住。

**动作方向反了 / 角度不对**
- 不要硬掰舵机；先确认摇臂装配角度，再用网页调参或 `set_trim` 微调；
- 嘴巴和脖子的机械限位是死的：嘴 45–60°，脖子 45–180°，代码里已经钳住。

---

## 十一、安全与保养

- **不要用手硬掰舵机**，尤其是嘴巴和脖子，会打齿；
- 摔倒、卡住时它会自己停，但别让它长时间堵转；
- 3D 打印件是 PLA/PETG，别放高温处（车内、暖气旁）；
- 电池不要过放，长期不用每隔一两个月充一次；
- 桌面使用，别放在桌沿。
