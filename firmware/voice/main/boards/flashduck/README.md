# Flashduck 机器鸭

Flashduck 是基于闪猫1号官方 DIY 套件摄像头版二次开发的机器鸭项目。硬件复用官方套件 CAM 板的 ESP32-S3、ST7789 240×240 圆屏、摄像头、音频和电池电路，但机械结构不同：

- 左右腿、左右脚沿用官方套件的四足/双足舵机结构；
- 原来的左手舵机位改为**嘴巴**（GPIO4，原 `left_hand_pin`）；
- 原来的右手舵机位改为**脖子**（GPIO7，原 `right_hand_pin`）。

## 舵机映射

| 部位 | 逻辑索引 | 摄像头版 GPIO | 说明 |
|---|---:|---:|---|
| 左腿 | `LEFT_LEG` | 5 | 内收/外展 |
| 右腿 | `RIGHT_LEG` | 43 | 内收/外展 |
| 左脚 | `LEFT_FOOT` | 6 | 上下翻转 |
| 右脚 | `RIGHT_FOOT` | 44 | 上下翻转 |
| 脖子 | `NECK` | 7 | 左右转动，正前方 135° |
| 嘴巴 | `MOUTH` | 4 | 单向上开，闭合 45°，最大 60° |

### 机械限位（重要）

- 脖子：`45° ~ 180°`，静止/正前方 `135°`；
- 嘴巴：`45°（闭合）~ 60°（全开）`，**绝对不要超过 60°**；
- 代码在 `Oscillator::Write()` 最终输出处做了钳位，任何动作路径都不能越过限位；
- 首次装配建议脱开舵机臂/限流，逐个确认方向后再上整机动作。

## 显示

屏幕上方 1/2 区域中央有一个 96px 的圆形眼睛：

- 瞳孔随机扫视，低速平滑跟随，带轻微停留；
- 每 3~7 秒随机眨眼，约 12% 概率连续眨两下；
- 眨眼使用上下眼睑闭合，闭合/睁开带 smoothstep 缓动；
- 眼睛使用 Flashduck 自己的单眼动画；摄像头预览时眼睛自动隐藏，预览结束恢复。
- 顶部状态栏（电池、网络、充电图标）保留。

## 动作与 MCP 工具

动作通过 `self.flashduck.action` 调用：

- 基础：`walk`、`turn`、`jump`、`swing`、`updown`、`sit`、`home`
- 脖子：`head_turn`（`direction`: 1 左 / -1 右 / 0 回正）、`head_shake`、`look_around`
- 嘴巴/趣味：`quack`（张嘴合嘴 1~3 次）、`chatter`（快速小声咂嘴）、`curious`（侧头好奇+轻叫）、`preen`（侧头理羽+咂嘴）、`happy_waddle`（开心走两步+轻叫）、`stretch`（伸懒腰）、`dance`（小段鸭舞）、`peck`（低头啄食+张嘴）、`yawn`、`sleepy`

动作集围绕鸭子形态组织，保留适合六舵机结构的行走、转向、头部和嘴巴动作。

其他工具：

- `self.flashduck.stop`
- `self.flashduck.get_status`
- `self.flashduck.set_trim` / `self.flashduck.get_trims`（`servo_type`: `left_leg/right_leg/left_foot/right_foot/neck/mouth`）
- `self.flashduck.get_ip`
- `self.battery.get_level`

动作结束后：`head_turn` 会保持转头角度；其余动作（包括 quack/curious/preen 等）回到中立姿态；`sit`/`home` 不额外复位。


## 顶部显示与提示音

- 屏幕顶部不再显示时间（HH:MM）和固件版本号；
- 启动时的 `BOARD_NAME/version` 系统消息、激活完成后的“版本 x.y.z”通知都会被过滤；
- 电池、网络、充电等状态图标仍保留。

联网成功、进入配网、激活提示音已替换为 Musevibe 项目的自定义配音：

- `main/assets/common/success.ogg`（联网/就绪）
- `main/assets/locales/zh-CN/wificonfig.ogg`（配网）
- `main/assets/locales/zh-CN/activation.ogg`（激活）

烧录时需要同时更新 app 和 assets 分区。

## 构建与烧录

```bash
source /path/to/esp-idf-v6.0.1/export.sh
python3 scripts/build.py flashduck --name flashduck --language zh-CN
```

生成的固件位于 app 镜像。摄像头支持 OV2640 / OV3660 / GC2145，电池充电状态检测复用官方套件摄像头版的无充电检测脚方案（USB + 电池电压趋势）。

## 宽站距步态调参

Flashduck 的腿间距比官方套件宽，默认 30° 髋摆 + 30° 脚摆容易变成“原地蹭”：

- 支撑面变宽后，重心更难移到支撑脚上方，摆动脚没有真正离地；
- 腿越外张，脚踝俯仰中用于前进的分量越少，横向刮擦越多；
- 原来的 `90°` 髋中位会让两只脚站得很开。

实机调好的一组宽站距参数已写入固件默认值，并在首次启动时写入 NVS：

| 参数 | 当前默认 | 作用 |
|---|---:|---|
| `hip_offset` | 25° | 双腿向身体中线内收，收窄支撑面 |
| `hip_amp` | 44° | 髋部左右摆幅，把重心移到支撑脚 |
| `foot_amp` | 34° | 脚踝前后摆幅，决定步幅 |
| `phase_deg` | 108° | 髋/脚相位差，控制抬脚与推地时序 |
| `speed` | 600ms | 每一步周期 |
| `head_swing` | 24° | 走路时脖子摆动 |

`self.flashduck.action` 的 `walk`/`turn` **不再单独传步态参数**，而是使用 NVS 里保存的默认值；这样语音说“往前走”和网页默认测试是同一条步态。要调整参数，使用下面的局域网页面，点“保存为默认”即可更新 NVS。

调参顺序建议：

1. 先只调 `hip_offset`，让脚落在身体中线附近、两脚不碰撞；
2. 再调 `hip_amp`，直到摆动脚能离地、身体明显左右换重心；
3. 再调 `foot_amp`，在“步幅变大”和“脚不打滑”之间取平衡；
4. 最后微调 `phase_deg`，让脚先抬起再往前推；
5. `speed` 先用当前 600ms，如果发热/抖/低电量掉步，再放慢到 700~800ms。

如果 `hip_offset` 到 25°（上限）仍觉得站距太宽，说明机械上腿的安装宽度/脚的角度也需要调整，单纯改舵机角度会把脚往内撇，容易别住。


## 空闲自然小动作

机器人完全空闲/待机时，会偶尔自己做一点小动作，不会在听、说、执行动作时插入：

- 每 10~22 秒随机一次，第一次在启动后 8~16 秒；
- 脖子轻微左转或右转 8~18°，不是大幅转头；
- 嘴巴同时做 2~4 次小幅张合，每次只开 5~12°，不会一直张着嘴；
- 转头、张嘴、合嘴、回正的速度每次随机变化（约 180~700ms/段）；
- 腿脚保持当前姿态，不会被小动作带着走；
- 小动作执行时间很短，期间如果有语音/网页动作，会在队列里等它做完再执行。

这样看起来更像一只会东张西望、偶尔咂嘴的鸭子，而不是待机时完全不动。

## 局域网步态调参页面

Flashduck 启动并连上 WiFi 后，会开启一个局域网 HTTP 调参页：

- 端口默认 `80`；如果 80 被占用会自动退到 `8080`；
- 串口日志会打印 `Flashduck 调参页面: http://<IP>/`；
- 手机/电脑连同一个 WiFi，打开这个地址即可。

页面提供六个可拖动参数（步长 1° 或 50ms）：

| 页面名称 | 参数 | 当前默认 | 作用 |
|---|---|---:|---|
| 双脚内收 | `hip_offset` | 25 | 双脚往身体中线收，收窄支撑面 |
| 身体左右摆幅 | `hip_amp` | 44 | 左右换重心的幅度 |
| 脚踝摆幅 / 步幅 | `foot_amp` | 34 | 一步迈多大 |
| 抬脚时序 | `phase_deg` | 108 | 髋/脚相位差 |
| 每一步时间 | `speed` | 600 | 周期，越大越慢 |
| 走路时脖子摆动 | `head_swing` | 24 | 0 表示不摆头 |

点击“向前走 5 步”或“向后走 5 步”会立即用当前滑块参数执行 5 步，无需重新烧录。参数只影响下一次测试，不会打断正在执行的动作。“停止 / 回正”可随时打断。

调好后点 **“保存为默认”**，页面会把当前六个参数写入机器人 NVS；之后：

- 重新打开页面会载入这组默认值；
- 语音调用 `self.flashduck.action` 的 `walk`/`turn` 也会使用这组默认值；
- 点“恢复官方默认”只是把滑块填回默认数值，要点“保存为默认”才会永久生效。
